Proyecto para simular el tráfico vehicular en un cruce, analizando el flujo, tiempos de espera y eficiencia de los semáforos.

Características
• Conteo de vehículos que cruzan y los que generan tráfico (tiempo de espera).

• Identificación del semáforo con mayor flujo vehicular y el que causa mayores demoras.

• Cálculo de tiempos de espera para la disipación del tráfico.

• Interfaz gráfica dedicada para la visualización de estadísticas detalladas.

Requisitos
• Python

• Pygame

Uso
Ejecuta el script principal para iniciar la simulación y observa las estadísticas en la interfaz correspondiente.
